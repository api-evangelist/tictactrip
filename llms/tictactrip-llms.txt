# Tictactrip API

> Tictactrip is a European multimodal travel search and booking aggregator. One REST API combines train and bus inventory from 250+ carriers across 20+ European countries into single itineraries, with CO2 emissions per journey and a complete booking workflow (search, cart, order, book, ticket, cancel). Base URL: https://api.tictactrip.eu. Authentication is a bearer JWT partner token (request via sales@tictactrip.eu).

## APIs
- [Tictactrip API reference](https://developers.tictactrip.eu/api): 20 REST operations across discovery (segment providers, stop groups/clusters, autocomplete, popular cities, trip results) and booking (carts, orders, book, tickets, cancellation).
- [OpenAPI specification](https://api.tictactrip.eu/documentation): OpenAPI 3.0.0, served live from the API host.

## Getting started
- [Introduction & tutorial](https://developers.tictactrip.eu/docs/intro): from zero to first booking in four calls.
- Quick start flow: (1) authenticate with your bearer token; (2) resolve city ids via GET /v2/stopClusters or GET /v2/autocomplete; (3) search itineraries via POST /v2/results; (4) create a cart, order and book via /booking/v3.
